# Student Performance & Learning Analytics

## Project Overview

This project analyzes student academic performance, study time, absences, and grades using Python and machine learning.

## Objectives

* Clean and explore student data.
* Analyze attendance and academic performance.
* Visualize grade distributions and correlations.
* Build a model to predict final student grades.
* Evaluate model performance.

## Dataset

UCI Student Performance Dataset
https://archive.ics.uci.edu/dataset/320/student+performance

## Tools and Technologies

* Python
* Pandas and NumPy
* Matplotlib and Seaborn
* Scikit-learn
* Jupyter Notebook

## Project Workflow

1. Data collection
2. Data cleaning
3. Exploratory data analysis
4. Attendance and grade analysis
5. Data visualization
6. Feature engineering
7. Linear Regression modeling
8. Model evaluation

## Results

The project explores factors associated with student performance and evaluates a model for predicting final grades.

## Conclusion

This project demonstrates the use of data analysis and machine learning to understand student academic performance.
